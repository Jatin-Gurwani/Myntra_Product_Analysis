# 🛍️ Myntra Product Analysis

An exploratory data analysis project on Myntra product data using **Python, Pandas, Plotly, and Jupyter Notebook** to understand product pricing, discounts, ratings, brands, categories, and other catalog-level patterns.

## 📌 Project Overview

This project analyzes a Myntra product dataset to extract meaningful insights from product-level information.

The analysis focuses on:

- Product and category distribution
- Brand-level analysis
- Product pricing and discount patterns
- Customer ratings and reviews
- Identification of trends and outliers
- Interactive data visualization

The project demonstrates an end-to-end **Exploratory Data Analysis (EDA)** workflow, from loading and cleaning raw data to analyzing patterns and presenting visual insights.

## 🎯 Objectives

The main objectives of this project are to:

1. Explore the structure and characteristics of the Myntra product dataset.
2. Clean and prepare the data for analysis.
3. Analyze product prices and discount patterns.
4. Study product ratings and review-related attributes.
5. Identify patterns across brands and categories.
6. Create visualizations to communicate key findings.

## 🔍 Analysis Performed

### 1. Data Exploration

The dataset was explored to understand:

- Number of products
- Available attributes
- Data types
- Missing values
- Duplicate records
- Distribution of numerical features

### 2. Data Cleaning

The analysis includes preprocessing steps such as:

- Handling missing values
- Removing or identifying duplicate records
- Cleaning categorical/text data
- Converting numerical columns into appropriate formats
- Identifying potential outliers

### 3. Product Analysis

Product-level attributes were analyzed to understand:

- Product distribution
- Price ranges
- Discount patterns
- Rating distribution
- Review counts
- Product popularity indicators

### 4. Brand & Category Analysis

The project explores product distribution across:

- Brands
- Categories
- Product types

This helps identify brands and categories with higher product representation and understand the composition of the Myntra catalog.

### 5. Pricing & Discount Analysis

Pricing-related attributes were analyzed to identify:

- Price distribution
- Discounted vs. original prices
- Discount patterns
- High- and low-priced products
- Potential pricing outliers

### 6. Ratings & Reviews

Customer feedback-related attributes were explored to understand:

- Rating distribution
- Highly rated products
- Products with significant review counts
- Relationship between ratings and product attributes

## 💡 Key Takeaways

The analysis helps provide a catalog-level view of Myntra products and highlights patterns related to:

- Product assortment
- Brand presence
- Category distribution
- Pricing strategies
- Discounting
- Customer ratings and engagement

These insights can be useful for understanding **e-commerce product catalogs and customer-facing product attributes**.

## 🚀 How to Run


### 2. Install dependencies

```bash
jupyter notebook
```

Open:

```text

```

and run the notebook cells sequentially.
